# Htin Zaw Portfolio

A personal portfolio website showcasing my projects, technical skills, and professional background.

## Project Overview

This portfolio website was built using a Bootstrap template as a foundation and then customised to create a personal online portfolio. The project was modified to reflect my own design preferences, content, and professional profile.

The website provides information about my technical skills, projects, work experience, and contact details.

## Features

* Responsive design for desktop and mobile devices
* Personal profile and skills section
* Project showcase
* Professional experience section
* Contact form with email functionality
* Customised Bootstrap-based layout and styling

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap
* PHP (Contact Form)

## Customisations

The original Bootstrap template was redesigned and customised to:

* Reflect my personal branding
* Showcase my development projects
* Present my technical skills and experience
* Provide a simple contact method for visitors

## Installation

Clone the repository:

```bash
git clone https://github.com/htinz/htin-zaw-portfolio.git
```

Navigate to the project directory:

```bash
cd htin-zaw-portfolio
```

Open `index.html` in your browser or deploy the project to a web server.
